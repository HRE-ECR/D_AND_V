# Information needed to finish the live deployment

1. GitHub repository URL and default branch name.
2. Supabase Project URL.
3. Supabase publishable key (or legacy anon key). Do not send a secret/service-role key.
4. Final GitHub Pages URL, once known, for Supabase redirect configuration.
5. Email address(es) that should have the admin role.
6. Whether public sign-up must remain disabled and accounts will be created centrally.
7. Organisation/app name, logo and preferred colours, if different from the supplied design.
8. Approved wording for urgent safety issues, privacy notice and data retention period.
